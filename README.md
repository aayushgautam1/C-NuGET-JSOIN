# C-NuGET-JSOIN
A C# console app that uses Newtonsoft.Json to handle JSON files, deserialize data into objects, and demonstrate inheritance, file operations, and loops.

## Separate commits per task (version history)
- Task 1 & 3 – Manual JSON file (`users.json`), deserialize, loop output.
- Task 2 – Add new entry (`Alice Brown`) to JSON object.
- Task 4 – Inheritance: `Admin` and `RegularUser` extend `User`.
- Task 5 – Create `specialized_users.json` with `Admin` and `RegularUser`, deserialize and output.
- XML reader – Example from theory: read `users.xml` and print.

## Technologies
- C# .NET 10
- Newtonsoft.Json
